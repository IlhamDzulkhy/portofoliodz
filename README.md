# Ilham Dzulkhy — Portfolio

Portfolio profesional Ilham Dzulkhy, siap deploy di GitHub Pages.

## 🚀 Cara Deploy ke GitHub Pages

### Langkah 1 — Buat Repositori GitHub
1. Buka [github.com](https://github.com) → klik **New repository**
2. Nama repo: `ilhamdzulkhy.github.io` (atau nama bebas, misalnya `portfolio`)
3. Set ke **Public**
4. Klik **Create repository**

### Langkah 2 — Upload File
**Via browser (tanpa Git):**
1. Di halaman repo yang baru dibuat, klik **uploading an existing file**
2. Drag & drop file `index.html` ke sana
3. Klik **Commit changes**

**Via Git (terminal):**
```bash
git init
git add index.html
git commit -m "Initial portfolio"
git remote add origin https://github.com/USERNAME/NAMA-REPO.git
git push -u origin main
```

### Langkah 3 — Aktifkan GitHub Pages
1. Di repositori, klik **Settings** → **Pages** (sidebar kiri)
2. Di bagian **Source**: pilih branch `main`, folder `/ (root)`
3. Klik **Save**
4. Tunggu 1–2 menit → website aktif di `https://USERNAME.github.io/NAMA-REPO`
